# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub's private reporting form: go to the repository's **Security** tab and choose **Report a vulnerability**, or open <https://github.com/k8s-m8s/k8s-m8s/security/advisories/new>. Only the maintainers can see the report.

Please include what you found, how to reproduce it, and what you think the impact is. You will get a reply as soon as a maintainer has read it. Please allow time for a fix before disclosing the problem publicly.

## What counts

In scope:

- the scripts and GitHub workflows in this repository
- the published site at <https://docs.k8s-m8s.io/>
- anything in the repository that should not be public, such as a credential

Not a security report:

- **Wrong or outdated compatibility data.** Open a "Data correction" issue with a link to the upstream statement.
- **Vulnerabilities in a listed tool or in Kubernetes.** Report those to that project.

## Supported versions

Only the current `main` branch and the currently published site are maintained.
